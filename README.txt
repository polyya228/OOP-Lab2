Лабораторная работа №2: Паттерны Observer, Proxy, Strategy

Требования:
- Компилятор с поддержкой C++17.
- Visual Studio 2019/2022.

Структура проекта
- "Observer.h" - интерфейсы IObserver/IObservable, структура UnitEvent.
- "UnitTypeInfo.h/.cpp" - пул характеристик юнитов (unordered_map).
- "Unit.h/.cpp" - абстрактный базовый класс юнита (наследник IObservable).
- "Units.h/.cpp" - конкретные юниты (Infantry, Archer, Mage, Flying).
- "UnitFactory.h" - фабрика для создания юнитов.
- "Terrain.h" - интерфейс ландшафта и его реализации (Plains, Forest, Swamp, Mountains).
- "TerrainProxy.h/.cpp" - прокси для ландшафта (проверки для летающих).
- "NeutralObject.h/.cpp" - стратегии и нейтральные объекты (сундук, ловушка, алтарь, источник).
- "Base.h/.cpp" - игровая база (наблюдатель, создатель юнитов).
- "TerrainMap.h/.cpp" - карта (матрица ландшафта, список юнитов и объектов).
- "GameController.h/.cpp" - управление, главный цикл, сценарии.
- "main.cpp" - точка входа.

Сборка и запуск (Visual Studio):
1. Откройте файл решения ".sln" в Visual Studio.
2. Убедитесь, что в свойствах проекта ("C/C++ → Язык → Стандарт языка C++") выбран "ISO C++17" или новее.
3. Убедитесь, что в свойствах проекта ("C/C++" → "Командная строка") добавлен флаг "/utf-8" (для корректного вывода русского текста).
4. Нажмите "Сборка" → "Пересобрать решение" (или "Ctrl+Shift+B").
5. Запустите программу ("F5" или "Ctrl+F5").
